# OCC / Pocket edition

Визуальный источник — профиль HVHBIGNAME, `assets/hero-dark.svg`: тёмный графит с оливковым подтоном, лаймовый акцент, инженерная сетка, ядро в орбитах, короткие моноширинные подписи.

Логотип — лёгкий изометрический контейнер и внутреннее ядро. Система экранов: обзор, сессии, диалог/изменения/задачи/файлы, входящие, модели, настройки. На широком экране — боковая навигация; на телефоне — нижняя. Composer закреплён внутри области чата, учитываются safe-area и изменение viewport клавиатурой.

Фоновые уведомления не используют исходники как текст. Модальные окна используют нативный HTML dialog для focus trap. У иконок есть текстовые accessible labels, состояния имеют подписи кроме цвета, а `prefers-reduced-motion` останавливает декоративное движение.

Шрифты поставляются внутри приложения; при открытии не нужны Google Fonts или другие font CDN. Их лицензии — SIL Open Font License из соответствующих npm-пакетов. Внешняя ссылка на GitHub явно открывается отдельно.
