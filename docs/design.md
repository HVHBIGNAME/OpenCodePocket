# OCC / Pocket edition

Оформление использует все 37 оригинальных тем OpenCode и их светлые/тёмные варианты. Исходные JSON, оба алгоритма расчёта палитры и MIT-лицензия находятся в `third_party/opencode`; ревизия — `3f393d78bfc3f0826b2c7080e57964c235704695`. Цвета не подбираются по скриншотам: `scripts/sync-opencode-themes.mjs` воспроизводит точные upstream-токены, а `npm run themes:check` проверяет результат без сети.

| Токен | Значение |
| --- | --- |
| Background | `--background-base` |
| Surface | `--surface-base` |
| Border | `--border-base` |
| Primary text | `--text-base`, `--text-strong` |
| Secondary text | `--text-weak` |
| Interactive | `--text-interactive-base`, `--surface-interactive-base` |
| Pending | `--surface-warning-base`, `--text-on-warning-base` |
| Error | `--surface-critical-base`, `--text-on-critical-base` |
| Main type | Manrope, статические 400 / 600 / 700 / 800 |
| Data / code | IBM Plex Mono |

Логотип — лёгкий изометрический контейнер и внутреннее ядро. OCC предназначен для мобильных устройств. Главный экран — сессии, нижние вкладки — сессии, запросы, модели и настройки. В открытом чате навигация скрывается, чтобы отдать место переписке. Выбор модели/агента/варианта и действия с сессией открываются нижними панелями.

Текст чата — 15–16 px, основные действия — не меньше 44–48 px по высоте. Список сессий обновляется свайпом вниз. Новая сессия доступна плавающей кнопкой. Вопросы с несколькими частями показываются пошагово с сохранением ответов при возврате. Запросы доступа вынесены в заметную панель над вводом. Composer закреплён внутри чата; Capacitor Keyboard изменяет нативную область экрана при показе клавиатуры. Автопрокрутка не забирает позицию у пользователя, читающего старые сообщения.

Фоновые уведомления не используют исходники как текст. Модальные окна используют нативный HTML dialog для focus trap. У иконок есть текстовые accessible labels, состояния имеют подписи кроме цвета, а `prefers-reduced-motion` останавливает декоративное движение.

Шрифты поставляются внутри приложения; при открытии не нужны Google Fonts или другие font CDN. Их лицензии — SIL Open Font License из соответствующих npm-пакетов. Внешняя ссылка на GitHub явно открывается отдельно.

По умолчанию выбрана Mercury Dark. «Настройки → Оформление» позволяет выбрать любую тему с поиском, переключить режим или следовать системе. Выбор хранится локально и применяется до первого React-рендера. Системные панели и клавиатура iOS следуют светлому/тёмному режиму. Нативные стартовые изображения используют Mercury; после загрузки применяется сохранённая тема.
