# OpenCode Pocket 1.0.0 — Within reach

Твой код. Всегда рядом.

Первый выпуск OCC для Android и iOS: мобильные сессии OpenCode, полноэкранный чат и **37 оригинальных тем OpenCode** в светлом и тёмном режимах. По умолчанию — Mercury; шрифты Manrope / IBM Plex Mono поставляются внутри приложения.

## Внутри

- Все темы OpenCode 1:1 по исходным палитрам и алгоритмам расчёта цветов. Поиск по каталогу, светлый/тёмный/системный режим и сохранение выбора.
- Мобильная навигация, нижние панели выбора модели/агента/варианта, пошаговые вопросы и ввод, учитывающий экранную клавиатуру.
- Подключение по одноразовому QR, через OCC-плагин, существующий туннель или прямо к OpenCode.
- Актуальные сессии, потоковые ответы, инструменты, файлы, патчи и задачи.
- Промпты, вложения, slash-команды, остановка, ответвление и переименование сессий.
- Вопросы с несколькими ответами, разрешения и правила автодоступа.
- Модели, агенты, варианты, API-ключи и свои OpenAI-совместимые провайдеры.
- Нативная диктовка: Android SpeechRecognizer и iOS Speech framework. По умолчанию — только локально.
- Android: фоновое соединение с уведомлениями. iOS: APNs при настройке ключей на мосте и корректной подписи приложения; также поддерживается внешний канал ntfy.
- Ключи и черновики: Android Keystore + AES-GCM, iOS Keychain. Отзыв отдельных устройств.
- Автоотчёты о сбоях: ограниченная очередь на телефоне, Android uncaught exceptions / iOS MetricKit, строгая схема без промптов и секретов, устранение дублей и GitHub Issues через `gh` на компьютере. Переключатель в настройках.

## Проверки

- 40 unit/integration проверок и сверка всех тем с оригинальными исходниками.
- 30 мобильных браузерных сценариев: компактный Android, Pixel 7 и iOS WebKit. Все 74 цветовых варианта проверены на каждой платформе.
- Интеграция с настоящим OpenCode 1.18.32: установка плагина, авторизация, сессии и обновление общей конфигурации.
- Нативный Android smoke: Keystore, HTTP/SSE, клавиатура, фоновое уведомление и восстановление подключения.

## Быстрый старт

Установите Node.js 22+ и [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/), затем на компьютере:

```sh
npx --yes --package=https://github.com/HVHBIGNAME/OpenCodePocket/releases/download/v1.0.0/hvhbigname-occ-bridge-1.0.0.tgz occ-pocket install --tunnel
```

Перезапустите OpenCode: `opencode --port 4096`. Откройте `~/.config/opencode/occ-pocket/pairing.html`, затем в OCC нажмите «Подключить компьютер» и отсканируйте QR.

[Подключение](https://github.com/HVHBIGNAME/OpenCodePocket/blob/main/docs/connect.md) · [Уведомления](https://github.com/HVHBIGNAME/OpenCodePocket/blob/main/docs/notifications.md) · [Сборка и подпись iOS](https://github.com/HVHBIGNAME/OpenCodePocket/blob/main/docs/build.md)

В этой версии код исполняется на подключённом компьютере. Локальная среда исполнения на телефоне в выпуск 1.0 не входит.
