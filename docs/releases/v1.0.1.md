# OpenCode Pocket 1.0.1

## Установка плагина

- **Windows:** скачать `Install-Pocket.cmd` из Assets и запустить двойным щелчком.
- **macOS / Linux:** `curl -fsSL https://github.com/HVHBIGNAME/OpenCodePocket/releases/download/v1.0.1/install-pocket.sh | sh`.
- Установщик сам подготавливает Node.js при необходимости, скачивает `cloudflared` и проверяет SHA-256. Права администратора не нужны.
- После установки перезапустить OpenCode и выполнить **`/pocket-qr`**.
- **`/pocket`**, **`/pocket-status`**, **`/pocket-config`**: подключение, статус и настройки. В TUI доступны локальные меню; desktop-команды используют инструмент плагина через агента.
- Существующие JSONC-настройки и плагины сохраняются. Изменение режима подключения требует перезапуска OpenCode.

## Интерфейс и клавиатура

- Убраны слоганы, крупные логотипы и рекламные блоки. Стартовый экран — подключение, после него — сессии.
- Длинные ошибки показываются компактно; полный текст доступен по кнопке «Подробнее».
- Поля ввода используют размер не меньше 16 px для предотвращения автозума iOS.
- Высота чата и диалогов следует видимой области при клавиатуре; нажатие вне полей закрывает клавиатуру.
- iOS: отключено растягивание внешнего WebView, включено интерактивное закрытие клавиатуры.
- Исправлен таймаут iOS HTTP: загрузка фото больше не ограничивается 15 секундами. Крупные фото уменьшаются до 2048 px и сжимаются перед отправкой; после ошибки файл и текст остаются для повторной попытки.
- Отмена генерации отображается один раз по-русски, без дублирующего уведомления об ошибке.
- Переданные сервером рассуждения раскрываются и обновляются в потоке. Для пустых блоков явно указано, что сервер не передал текст.

## Подключение

QR туннеля выдаётся только после проверки публичного `/healthz`. Ошибка Cloudflare 530 больше не считается готовым соединением. Если Cloudflare недоступен, выберите LAN в `/pocket-config`: iPhone и ПК должны быть в одной сети.

## Файлы

- `OpenCodePocket-1.0.1-android.apk` — подписанный APK.
- `OpenCodePocket-1.0.1-ios-unsigned.ipa` — IPA без Apple-подписи; устанавливается через Sideloadly/AltStore или свою Apple-команду.
- `hvhbigname-occ-bridge-1.0.1.tgz` — пакет плагина и CLI для Node.js 22+.
- `Install-Pocket.cmd`, `install-pocket.ps1`, `install-pocket.sh` — установщики.
- `occ-pocket-*.mjs` — автономные компоненты установщика.
- `SHA256SUMS.txt` — контрольные суммы всех файлов.
